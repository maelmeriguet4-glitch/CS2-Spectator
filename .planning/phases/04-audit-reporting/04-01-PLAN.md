# Plan 04-01: Exportateur de Rapport (Audit Reporting)

## Objective
Ajouter un bouton "Exporter Rapport" à l'interface DashboardPanel, et écrire un module `export.py` qui génère un fichier texte clair et professionnel.

## Components to Update / Create
1. **`src/core/export.py` [NEW]**
   - Créer une fonction `export_player_report(player: PlayerTelemetry, export_dir: str = "reports") -> str`
   - Le rapport inclura: 
     - L'entête CS2 Anti-Cheat
     - Le nom du joueur, le verdict, le score de suspicion.
     - Les `violation_flags` (les preuves).
     - Les métriques brutes (vitesse max, ratio bhop, etc.).
2. **`src/ui/components/dashboard_panel.py` [MODIFY]**
   - Ajouter un bouton "Exporter" dans la ligne de l'accordéon (`PlayerResultRow`), à côté de "Détails".
   - Binder le bouton à la fonction `export_player_report` et afficher un tooltip ou une popup de confirmation de sauvegarde.

## Verification
- Tester l'export sur un joueur suspect.
- Vérifier que le dossier `reports/` se crée s'il n'existe pas, et que le fichier `.txt` contient les bonnes informations.
