# Plan 02-01: Advanced ML Detection & Metrics Extraction

## Objective
Intégrer les modèles de détection avancés pour l'aimbot et le wallhack, en utilisant `scikit-learn` (Isolation Forest) pour prédire de véritables probabilités (scores humanisés) et détecter les anomalies biomécaniques subtiles à partir des démos CS2.

   - Améliorer l'extraction des données d'aim pour capturer des comportements humains vs non-humains :

     - `overflick_rate`
     - `micro_adjustments`
2. `src/analyzers/wallhack.py`
   - Améliorer l'extraction pour le wallhack (placement du viseur à travers les murs, pre-fire sans ligne de vue).
3. `src/ml/classifier.py`
   - Implémenter la classe `CheatClassifier` pour utiliser un modèle `scikit-learn` :
     - Un algorithme de détection d'anomalies type **Isolation Forest** ou un système par classification supervisée.
     - S'il n'y a pas de dataset pré-entraîné fourni, implémenter un modèle qui peut être calibré ou initialisé avec des poids statiques, puis simuler la prédiction du score en pondérant les prédictions d'Isolation Forest et des règles expertes.
   - Fournir des "verdicts" clairs (CLEAN, SUSPECT, CHEATER) basés sur la probabilité.
